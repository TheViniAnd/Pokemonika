[SIZE=5][COLOR=#169d9a][B]A Pokémon adventure on your Minecraft server[/B][/COLOR][/SIZE]
Pixelmonika brings animated, block-built Pokémon into your world using Minecraft's existing textures. Choose a starter, discover wild encounters, weaken opponents in turn-based battles and catch them with a red-and-white Poké Ball. Players join with an ordinary Minecraft Java client.

[SIZE=5][COLOR=#169d9a][B]How battles and catching work[/B][/COLOR][/SIZE]
Right-click a wild Pokémon with an empty hand to open the battle menu. Select a move, switch a teammate, attempt a catch or flee. Each move spends PP. Its power and type interact with the Pokémon's stats; speed plus the move's speed bonus decides turn order. Victories award experience.

Use a plugin Poké Ball in the world or choose one in battle. Weakened, lower-level targets are easier to catch. The formula uses configurable server rules. Fainted targets cannot be caught.

[CENTER][IMG]https://raw.githubusercontent.com/TheViniAnd/Pokemonika/main/assets/screenshots/poke-ball.png[/IMG]
[I]The thrown/capture model is red and white. In the inventory and hand, the base item looks like a vanilla snowball.[/I][/CENTER]

The default recipe produces four balls:
[CODE]
Redstone   White Wool   Redstone
White Wool Snowball     White Wool
Redstone   White Wool   Redstone
[/CODE]
View it in game with [B]/pixelmonika balls[/B].

Pokémon models are protected from ordinary Minecraft damage. During a Pokémon battle, incoming and outgoing Minecraft combat involving its player is blocked, including other players' interference. Outside these battles, normal server PvP rules apply.

[SIZE=5][COLOR=#169d9a][B]Install and start playing[/B][/COLOR][/SIZE]
[LIST=1]
[*]Use [B]Paper 26.3 with Java 25[/B] and stop your server.
[*]Put [B]Pixelmonika-Free-2.2.0-spigot.jar[/B] into the plugins folder. Install one JAR and one edition only.
[*]Start Paper. The compact build downloads pinned SQLite JDBC 3.50.3.0 through Paper's library loader; the server needs access to Maven Central.
[*]Check the allowed world names in [B]plugins/Pixelmonika/spawns.yml[/B]. The default world is named [B]world[/B].
[*]Run [B]/pixelmonika starter[/B], choose your Pokémon and explore.
[/LIST]
The alternative [B]Pixelmonika-Free-2.2.0.jar[/B] already bundles SQLite. Both builds have the same gameplay; use either one.

English is enabled by default. To use Russian, set [B]language: ru[/B] in [B]plugins/Pixelmonika/config.yml[/B], run [B]/pixelmonika admin reload[/B] outside battles, throws and pending saves, then reopen menus.

[SIZE=5][COLOR=#169d9a][B]Player commands[/B][/COLOR][/SIZE]
[LIST]
[*][B]/pixelmonika[/B] — party or current battle.
[*][B]/pixelmonika starter[/B] — one-time starter choice.
[*][B]/pixelmonika heal[/B] — restore party HP and PP outside battle; default cooldown 60 seconds.
[*][B]/pixelmonika balls[/B] — ball information and recipe.
[*][B]/dex[/B] — Pokédex.
[*][B]/pc[/B] — 45-slot storage.
[/LIST]
Aliases for the main command: [B]/pokemonika, /creatures, /vm, /pk[/B].

[SPOILER=Administrator commands and permissions]
[CODE]
/pixelmonika admin give <player> <species> <level>
/pixelmonika admin spawn <species> <level>
/pixelmonika admin balls <player> [poke] <amount>
/pixelmonika admin clear
/pixelmonika admin reload
/pixelmonika admin stats
[/CODE]
Species IDs: pikachu, charmander, bulbasaur, squirtle, eevee, magikarp, slowpoke, pidgey, psyduck, vulpix.
Levels: 1–100. Administrative ball amounts: 1–1024.

[B]pixelmonika.play[/B] — gameplay; everyone by default.
[B]pixelmonika.admin[/B] — administration; operators by default.
Legacy pokemonika.play/admin and vanillamon.play/admin permissions remain supported. An explicit denial on a corresponding permission takes priority.
[/SPOILER]

[SIZE=5][COLOR=#169d9a][B]Technical information[/B][/COLOR][/SIZE]
[LIST]
[*][B]Target:[/B] Paper 26.3, API build 230, Java 25. This is a Paper plugin distributed on SpigotMC; plain Spigot, Folia, Bedrock and other Minecraft versions are not supported by this release.
[*][B]Rendering:[/B] BlockDisplay parts, Interaction hitboxes and TextDisplay labels with client interpolation. Standard Minecraft textures, sounds and particles.
[*][B]Data:[/B] serialized SQLite work on a dedicated worker; transactional capture/reward records. Player data is stored in vanillamon.db inside the plugin folder.
[*][B]Default limits:[/B] 20 wild Pokémon globally, three near a player and at most 12 models visible to a player within 32 blocks. Spawn checks every 1,200 ticks; admission probability 0.25. Limits are configurable, not a guarantee of player capacity or TPS.
[*][B]Effects:[/B] up to 24 active scenes and 240 particles per tick by default.
[*][B]Configuration:[/B] worlds, habitats, stats, moves, models, effects, recipes, healing and language are editable.
[/LIST]
Back up the entire plugin data folder with the server stopped before updating. Do not import Premium databases or configurations into Free. Migration from older Pokemonika-branded Free builds is documented in the README.
