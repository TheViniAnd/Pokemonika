В локальной папке проекта иконка находится по пути `assets/branding/icon-96.png`. Весь комплект ZIP вместо JAR загружать не нужно.

Нумерация соответствует текущим `plugin.yml` и имени JAR. Название Git-коммита `release v 0.1` не меняет версию плагина; не указывай `0.1` как версию этого JAR.

Набор полей и список версий зависят от формы SpigotMC. Если `26.3` отсутствует в списке, укажи Paper 26.3 / Java 25 в доступном текстовом поле и описании; другую версию вместо неё не выбирай.
