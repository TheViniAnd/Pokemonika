# Pixelmonika — публикация Free на SpigotMC

Основное описание подготовлено на английском. Внутри плагина доступны английский по умолчанию и русский через `language: ru`.

## Что готово

- [Поля формы публикации](fields.ru.md): название, краткое описание, версия, требования и ссылки.
- [Полное описание BBCode](description.en.bbcode.txt): баннер, все три скриншота, иконка, механики, команды, техническая часть и ссылка покупки Premium.
- [README на английском](../../README.md) и [на русском](../../README.ru.md).
- [Баннер](../../assets/branding/banner.png), [иконка для загрузки](../../assets/branding/icon-96.png) и [оригинал иконки](../../assets/branding/icon.png).

Слоупок и стандартный покебол демонстрируют Free. Фото Генгара и Венузавра размещено в нижней части описания, в явно обозначенном разделе Premium. Шейдеры на скриншотах не являются обязательной частью плагина.

## 1. Открой страницу добавления ресурса

На SpigotMC войди в аккаунт и открой Resources → Add Resource. Выбери категорию бесплатных серверных плагинов, соответствующую Fun. Если ресурс уже существует, открой его редактирование вместо создания дубликата.

Картинки описания размещены в папке `assets/` репозитория [TheViniAnd/Pokemonika](https://github.com/TheViniAnd/Pokemonika). BBCode уже содержит прямые публичные адреса баннера, иконки и трёх скриншотов. Загружать их по одному в текст описания не требуется.

## 2. Выбери JAR

На страницу ресурса загружается **`Pixelmonika-Free-2.2.0-spigot.jar`**. Это компактная сборка: при первом запуске Paper загружает закреплённую SQLite JDBC 3.50.3.0. Серверу нужен доступ к Maven Central.

Для сервера без загрузки библиотек есть **`Pixelmonika-Free-2.2.0.jar`** со встроенной SQLite. Механики одинаковые. Игрокам не нужно устанавливать ни один из этих файлов — они устанавливаются на сервер. Одновременно используется один JAR одной редакции.

Требования: **Paper 26.3 и Java 25**. Размещение на сайте SpigotMC не означает поддержку обычного сервера Spigot.

## 3. Заполни ресурс

1. Войди на SpigotMC, открой Resources → Add Resource и выбери категорию бесплатных серверных плагинов, соответствующую Fun.
2. Перенеси значения из [fields.ru.md](fields.ru.md). Версия JAR — **2.2.0-free**.
3. Загрузи компактный JAR и `assets/branding/icon-96.png` как иконку. В скачанном комплекте эти файлы находятся внутри `plugin/`.
4. Переключи редактор описания в режим BBCode и вставь [description.en.bbcode.txt](description.en.bbcode.txt) целиком. В файле уже есть прямые адреса изображений.
5. Проверь предпросмотр: баннер сверху; два снимка Free внутри описания; кадр Premium и Boosty внизу; GitHub и поддержка открываются.
6. В поле Tested Versions отмечай только версию, которую проверил на своём сервере. Автоматические проверки не заменяют игровой запуск.
7. Опубликуй ресурс после своей проверки. Готовый комплект сам ничего не публикует на SpigotMC.

Если режим вставки BBCode недоступен, добавь изображения через кнопку редактора «Image», используя те же прямые ссылки, затем перенеси текст с форматированием.

## 4. Технические сведения для ответов пользователям

- 10 видов, 40 приёмов, один стандартный покебол; команда 6, ПК 45.
- Нет обязательных дополнительных плагинов, модов клиента или ресурс-пака.
- Компактная сборка скачивает SQLite через Paper; полная уже содержит библиотеку.
- Английский по умолчанию, русский через конфиг и `/pixelmonika admin reload`.
- Данные: `plugins/Pixelmonika/vanillamon.db`; резервируется вся папка при остановленном сервере.
- Free не включает PvP покемонов, спутников, эволюции, тренеров, гимы, обмены, задания, топы и покецентры.
- Premium: [boosty.to/minefind](https://boosty.to/minefind). Репозиторий Free: [TheViniAnd/Pokemonika](https://github.com/TheViniAnd/Pokemonika).
- Спавн, видимость и эффекты ограничены конфигурацией. Конкретный онлайн и TPS в описании не обещаются.
- Сборка и автоматические тесты не запускают Minecraft. Игровой запуск оставлен владельцу сервера.
