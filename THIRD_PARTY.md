# Dependencies and data

- Paper API 26.3.build.230-stable: compile/test dependency, not bundled in the plugin. https://papermc.io/
- SQLite JDBC 3.50.3.0: bundled in the full JAR; resolved by Paper in the compact marketplace JAR. Its own licence notices apply. https://github.com/xerial/sqlite-jdbc
- Gradle wrapper: build tooling. https://gradle.org/
- Base stats: pret/pokered, commit 171e2c204f9c1ff8e577ca387a4bbb009e130843. https://github.com/pret/pokered/tree/171e2c204f9c1ff8e577ca387a4bbb009e130843/data/pokemon/base_stats
- Dimensions/weight: PokeAPI, commit 286d7a071bc50ec4a57e3f3f506a13220ce6f903. https://github.com/PokeAPI/pokeapi/blob/286d7a071bc50ec4a57e3f3f506a13220ce6f903/data/v2/csv/pokemon.csv
